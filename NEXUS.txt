Name: Event List
Summary: Keeps the events list on the HUD to a fixed height that scrolls, with emergencies and the soonest countdowns on top.

Description (BBCode):
Tired of the events list running down your screen, or hiding events behind "...N more"? Event List keeps the list to a fixed height and lets the rest scroll. Emergencies and running countdowns move to the top so you never miss them.

[size=5]Main features[/size]
[list]
[*][b]Fixed height[/b]: the list stops at a set height and scrolls with the mouse wheel.[/*]
[*][b]Nothing hidden[/b]: the "...N more" cut never shows; every event stays in the list.[/*]
[*][b]Emergencies on top[/b]: emergencies and the zombie wave move to the top.[/*]
[*][b]Countdowns next[/b]: events with a running countdown come right after, the one about to run out first.[/*]
[*][b]Back to the top[/b]: when an event becomes important the list scrolls up to show it, but never while your pointer is on the list.[/*]
[*][b]Clicks work as before[/b]: clicks on the list and around it land where they did.[/*]
[/list]
Event List only changes how the list is drawn on screen. It never changes the game's data, adds nothing to your save and does not edit game files. You can remove it at any time.

Works in any game language.

[size=5]Known issues[/size]
The soonest-first order of countdowns is new in 0.2.0 and has not been tried in the game yet. With it on, a whole group can move: the normal events can sit above the main events when their countdown runs out sooner. Turn off CountdownSoonestFirst in the config if you prefer the game's order. The rescue and siege boxes are separate panels and stay where the game puts them. If you run into anything strange, please tell me (see Feedback below).
